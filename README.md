# population-density

This Rust workspace builds and queries the S2 population density database used by GrapheneOS.

## Architecture

S2PD is a memory-mapped quadtree topology format. It stores raw child masks through level 6 and restartable, context-dependent canonical Huffman masks through level 11. Compact rank indexes support direct traversal without reconstructing or caching the leaf vector. Successful queries for valid S2 cell IDs do not allocate on the heap.

The query engine retains the mapping without copying or persistently decompressing the database. [`QueryEngine::from_mmap`](core/src/lib.rs) validates the complete payload. `QueryEngine::from_verified_mmap` validates the layout, models, and indexes without decoding every Huffman mask; it is intended only for immutable bytes that already passed full and database-level query verification. `QueryEngine::open` maps a file directly and is unsafe because every process and writable alias must leave the mapped contents unmodified and untruncated until the engine is dropped.

NetworkLocation uses the preverified constructor for its immutable packaged resource. Arbitrary or newly generated bytes must pass the full constructor and the verifier before use with the preverified constructor.

## Data source

The database is generated from this WorldPop dataset:

- Dataset: `global_pop_2026_CN_1km_R2025A_UA_v1.tif`
- SHA-256: `bdfe7081506bd6123d43a29f22cf75ccdd6ea5fee3fdf7c3e9835debf71c6bc3`
- Download: [WorldPop Hub - global_pop_2026](https://hub.worldpop.org/geodata/summary?id=80032)

Verify the downloaded file with `sha256sum` before building. The pipeline aggregates pixel centers into level 12 S2 cells, accumulates population in deterministic fixed-point units, propagates values up the quadtree, and prunes cells below the 1,000-person threshold.

## Building and verifying

The LZW-compressed source requires the libtiff `tiffcp` utility on `PATH`. The builder uses it to create a temporary Deflate copy for decoding.

Place the pinned GeoTIFF at `data/global_pop_2026_CN_1km_R2025A_UA_v1.tif`, then build a local candidate database:

```bash
cargo run --release --package population-density-cli --bin build_database
```

The candidate is written to `population_density_database.bin`. The reviewed output currently has:

- Size: 578,752 bytes
- SHA-256: `cc44b8b2394663d8868688003b34187fd204664a45bc0117c57828c3d75c869c`

```bash
sha256sum population_density_database.bin
```

This output digest is a reproducibility aid in the documentation, not a Cargo or Soong build gate. A match establishes byte-for-byte equality with the reviewed output. It does not by itself establish how either file was produced. Investigate a mismatch before updating the packaged NetworkLocation resource or the reviewed output documentation.

Run the database verifier before review:

```bash
cargo run --release --package population-density-cli --bin verify_database
```

The verifier checks canonical encoding, full and preverified construction, identical leaf reconstruction, and query results for all 134,217,726 valid S2 cells through level 12. Use `--quick` for a deterministic sample during local iteration.

The benchmark measures warm-cache Rust query throughput with deterministic synthetic level 30 inputs:

```bash
cargo run --release --package population-density-cli --bin benchmark
```

## Purpose

The GrapheneOS population density provider uses on-device queries to select an S2 cell representing an estimated population of at least 1,000 people. Sparse locations therefore resolve to a coarser ancestor than dense locations.

## Testing

The integration tests require the pinned GeoTIFF at
`data/global_pop_2026_CN_1km_R2025A_UA_v1.tif` and `tiffcp` on `PATH`. They use
`population_density_database.bin` when present, then fall back to
`../../packages/apps/NetworkLocation/res/raw/population_density_database.bin`.
Build the local database first when running from a standalone checkout.

```bash
cargo test --release
cargo clippy --workspace --all-targets --all-features -- -D warnings
```

Release mode keeps the exhaustive integration tests practical.
